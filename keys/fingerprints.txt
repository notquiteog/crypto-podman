# Release-signing keys this bundle trusts, and how many must agree.
#
# These fingerprints are the trust anchor for update.sh.  Key material itself is
# fetched over the network, but nothing is imported unless its primary-key
# fingerprint appears below, so the transport does not have to be trusted --
# only this file, which is reviewable in git.
#
# Fingerprints are PRIMARY keys.  Several Bitcoin builders sign with subkeys;
# pinning a subkey would break the moment it is rotated.
#
# Format:
#   threshold <chain> <n>          minimum distinct good signatures required
#   key <chain> <fingerprint> <url-to-key>
#
# To review: every fingerprint below signed the currently pinned release, and
# was checked with `gpg --verify` against the upstream manifest on 2026-08-20.
